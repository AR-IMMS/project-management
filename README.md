# Project Management

This repository is used to manage project-level tasks and work items that are not tied to a specific code repository.

## Purpose

Use this repository for tasks such as:

- Business and product coordination
- Requirements clarification and review
- Stakeholder communication and approval
- UAT planning and coordination
- Project planning and release coordination
- Cross-team activities
- Other tasks that do not belong to a specific codebase

## What belongs here?

Create an Issue in this repository when the task is **not directly owned by a specific repository**.

For example:

- `Confirm ACI business requirements`
- `Get business approval`
- `Coordinate UAT`
- `Prepare release plan`

For implementation tasks, bugs, or technical work that clearly belongs to a specific codebase, create the Issue in the corresponding repository instead.

## Documentation

Project documentation such as requirements, specifications, meeting notes, and business documents may be maintained in external tools such as Google Drive or Google Docs.

When relevant, link the corresponding document in the Issue.

## GitHub Projects

Issues from this repository can be added to organization-level GitHub Projects alongside Issues from other repositories.

This provides a centralized view of project progress while keeping each task associated with the appropriate repository.
